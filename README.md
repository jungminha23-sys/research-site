# 미술사학자 하정민의 연구실 웹사이트

연구·수업 자료를 모아 보여주는 간단한 웹사이트입니다.
설치나 빌드 없이 파일 세 개로만 이루어져 있고, `main` 브랜치에 올리면 Netlify가 자동으로 사이트에 반영합니다.

## 파일 구성

| 파일 | 하는 일 |
| --- | --- |
| `index.html` | 사이트의 **글 내용** (제목, 소개, 자료 목록, 토론 주제). 대부분은 이 파일만 고치면 됩니다. |
| `style.css` | 사이트의 **모양** (색, 글꼴, 배치) |
| `script.js` | 휴대전화 메뉴 열기·닫기 등 작은 **동작** |

## 내용 고치는 법 (GitHub 웹사이트에서)

1. GitHub에서 이 저장소를 열고 `index.html`을 누릅니다.
2. 오른쪽 위 연필 모양(✏️ Edit) 버튼을 누릅니다.
3. `✏️` 표시가 있는 주석 아래의 글자를 원하는 내용으로 바꿉니다.
   - `<` `>` 로 둘러싸인 부분(태그)은 그대로 두고, 그 **사이의 글자만** 바꾸세요.
   - 예: `<p class="item-title">「옛 제목」</p>` → `<p class="item-title">「새 제목」</p>`
4. 아래쪽 **Commit changes** 버튼을 누르면 저장됩니다. 1~2분 뒤 사이트에 반영됩니다.

### 항목 늘리기·지우기

- **논문/발표 하나** = `<li class="item">` 부터 `</li>` 까지
- **과목 하나** = `<article class="course">` 부터 `</article>` 까지
- **토론 주제 하나** = `<article class="topic">` 부터 `</article>` 까지

이 덩어리를 통째로 복사해 바로 아래에 붙여 넣으면 항목이 하나 늘어나고, 통째로 지우면 사라집니다.

### PDF 등 파일 올리기

1. 저장소 첫 화면에서 **Add file → Upload files**로 파일을 올립니다. (예: `files` 폴더를 만들어 `논문2025.pdf` 업로드)
2. `index.html`에서 해당 링크의 `href="#"` 를 `href="files/논문2025.pdf"` 처럼 바꿉니다.

## 토론 의견 양식

토론 구역의 "의견 보내기" 양식은 Netlify Forms 기능을 사용합니다.
방문자가 보낸 의견은 사이트에 공개되지 않고, **Netlify 관리 화면 → 사이트 → Forms** 에서 확인할 수 있습니다.
(처음 한 번은 Netlify 관리 화면의 Forms 메뉴에서 양식 감지(Form detection)를 켜야 할 수 있습니다.)
